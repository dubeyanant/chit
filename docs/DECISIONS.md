# Architecture decisions

What was decided, and the reason that mattered. A supersession edits its record in place (CLAUDE.md
§0.2). **018, 026 and 030 are retired**, not reused — 018 moved to PACKAGES.md, 026 was absorbed by
040, 030 by 031. **021 and 041** are superseded and kept, a reversal being legible only beside what
it reversed. Everything else is accepted.

| | Decision | Why, and what it costs |
|---|---|---|
| 001 | Riverpod, with code generation | the screens are four readings of one table that must never disagree; Riverpod's graph gives that free |
| 002 | Three layers, and `features` never imports `data` | the seam is what lets a test refuse a microphone and a sync layer arrive later |
| 003 | Drift over a document store | nearly every screen is an aggregate query, which SQL answers in the database rather than in Dart |
| 004 | Local-only for v1, with the seams for sync | obliges a client-generated UUID per row — retrofitting stable ids onto a synced table is the expensive version. Cost: no backup |
| 005 | ~~Speech-to-text runs on the device~~ | **REMOVED by 058.** Over cloud STT, which means every recorded thought leaving a private journal. Kept, 013 and 014 citing it |
| 006 | A denormalised local day on every chit | a chit written at 00:20 belongs to that morning forever, and deriving the day at read time changes the answer across a timezone move |
| 007 | Ambient capture is best-effort and never blocks | a signal that does not arrive is null and is not drawn; capture may never delay the composer or fail a save |
| 008 | Audio on the filesystem, path in the row | stored **relative**, an absolute iOS container path being dead after the next update |
| 009 | Fonts bundled, not fetched | offline is a requirement and a fallback serif is a visibly different app. Cost: ~1.8 MB |
| 010 | Design tokens as a `ThemeExtension` | the accent's two weights and motion's per-kind reduced-motion behaviour are rules, enforceable only if one place knows them |
| 011 | `go_router` with a persistent tab shell | returning to a tab costs a fade, not a rebuild; the recording sheet stays a sheet, dismissing it not being a back navigation |
| 012 | An injected clock | three specified behaviours are functions of the current time; a fake clock makes the midnight rollover tested rather than discovered |
| 013 | A chit is text, audio, or both | independently nullable with at least one present. Its provenance half went with 058 |
| 014 | Saved chits are editable, and an edit never moves the moment | **audio half reversed by 063.** `createdAt`, `localDay` and the ambient fields are not parameters of any edit |
| 015 | Variable fonts, and weight through `fontVariations` | **a variable font renders at 400 whatever `fontWeight` says** — a silent failure, so every style sets both |
| 016 | Precise location first, coarse as the fallback | the motion ladder reads speed off the fix and find's map marks it (078, 089), neither of which a neighbourhood fix can carry — *it used to turn on the coarse place labels the backlog wanted, dropped by 101*. The row is precise enough to reconstruct an address, which is why 004 is load-bearing |
| 017 | The chit editor is a screen, and leaving it asks | a second editable field among the thread's rows makes it ambiguous which one a tap targets |
| 019 | Android and iOS only; `web/` stays | responsive web is planned, and regenerating it would be the only gain from deleting it |
| 020 | Reducing motion never makes a fade slower | press is the only acknowledgement a phone gives a finger. Found by a property test that failed on first run |
| 021 | ~~A chit is stamped when it is opened~~ | **SUPERSEDED by 040** — it filed a chit opened at 23:58 and saved at 00:05 on the previous day |
| 022 | The seal means now; a record is ink | over giving the accent to anything that mattered, which on a working screen is everything. Cost: density reads quieter |
| 023 | The field is live, but it does not take focus | a keyboard on every launch covers the thread and the strip, and reading back is as common a reason to open a journal as writing |
| 024 | The day arc becomes the timeline | three days, midnight to midnight, each mark at its actual time — the old window clamped 00:20 onto the same pixel as 5:00. *Resting at now was a scroll until 071 made it a jump* |
| 025 | The weather service takes no position | taking one would make weather wait on the slow precise fix and couple the two failures. Cost: the condition can be for where you were |
| 027 | An ambient loop is not a pace | the period belongs to the component that loops; one table holding both invites comparing quantities that are not comparable |
| 028 | The caret is the platform's, and chit draws none | an app that is animating when you open it is asking for something |
| 029 | The prompt reads the stamp | a generic prompt in front of a line reading `3:42 pm raining` ignores it. Every prompt stays a question — tested, since copy fails quietly |
| 031 | No widget tests | screen tests asserted tree structure rather than the visual claim and could not complete real I/O. |
| 032 | One day is one screen, and now rests in the middle | the unlabelled boundaries arrive where a reader expects them; resting at the end would pin 00:20 to the left edge |
| 033 | Today re-reads the clock at midnight | worse than a stale date, the first chit of the new day would save outside the drawn window and get no mark. Cost: it fires on the wall clock |
| 034 | A day passing is a haptic | the boundaries are deliberately hard to read, leaving nothing else to say you have scrolled into yesterday. Silent when the strip moves itself |
| 035 | Days with nothing in them are not drawn | narrows 024: a bare unlabelled line cannot be told from broken. A quiet day *between* two written ones still draws |
| 036 | Now is a tick, not a dot | over two built alternatives — a chit saved now sat *inside* the ring, and the disc that replaced it became the loudest thing on the screen |
| 037 | Motion is read off the position fix | An uncertain reading degrades to `stationary`, so noise can slow a chit down and never put a plane on one. No `running` or `cycling` |
| 038 | The stamp carries one ambient fact, ranked | three items at 11.5px is a ceiling, not a preference, and the two facts are usually alternatives anyway |
| 039 | Motion is drawn in the thread, not only on the open chit | almost no chit has a motion, so a word on two rows out of twelve carries real information. *An icon rather than a word until 078* |
| 040 | A chit is stamped when it is saved | reverses 021, absorbs 026: it removes the wrong-day class rather than patching its paths. Cost: the preview can disagree, and does not tick |
| 041 | Permission is asked once, behind a screen of our own — **reversed by 094** | a system prompt cannot say what it buys. It cost every install a screen to dismiss before a blank page, and the screen is gone; the ask is at a save now, in the context that explains it |
| 042 | Ambience is captured at launch and at save, never between | over capturing on every chit open, which made four taps cost four fixes. The row is written first and patched after, and **the patch moves neither `createdAt` nor `updatedAt`** |
| 043 | The weather mapping | `windy` at 7.0 m/s, and `wind_speed_unit=ms` pinned at the request, 8 km/h and 8 m/s being opposite verdicts. **078 moved rain and cloud off the summary code onto the measured quantities** |
| 044 | Twelve seconds, and a stale place beats no place | the fallback to a last known fix **drops its kinematics**, a stale speed otherwise claiming `traveling` about a desk |
| 045 | A reading stays good for one minute, **and said five until the owner walked it back** | set by the **place**, the shortest-lived signal: the window has to be shorter than a walk to the next room. Cost: a burst of chits buys a fix a minute rather than one for the sitting |
| 046 | Today's ring sits on paper, not on the tile | `--seal` on a density fill failed the 3:1 floor from three chits on, and a lighter ring breaks the one-accent rule |
| 047 | past draws only where something was written; **a chevron with nowhere to go is dimmed, not taken away** | a month that never will be written in reads as a day with nothing written in it. *It said "no chevron where there is nowhere to go" until 088* — a control that vanishes moves the two beside it |
| 048 | Every quiet week collapses, wherever it falls | narrows 047: the objection does not survive once day numbers are on the tiles. Cost: a month is no longer a calendar shape |
| 049 | past holds its last answer while the next is in flight | 007 read to its end — an empty state drawn while the real answer is in flight is a wrong answer, not a slow one |
| 050 | A day boundary is the tick at now, hanging below the line | at 4px a chit written near midnight hid it, so the signal failed exactly when a day was full |
| 051 | A record is short | one table row, not a five-headed essay; *it was a paragraph until this file became a table*, and both passes were applied retroactively. Cost: *how* a decision was reached now lives only in git |
| 052 | The recorder times a take on the clock, and reports a level | reading the duration back opens a decoder on the save path for one integer; the waveform draws a number, and the scale is the data layer's business |
| 053 | ~~The recogniser streams a split transcript~~ | **REMOVED by 058.** Kept, 054 and 055 citing it |
| 054 | A take goes through the repository; the wave is a window of levels | one door owns the temp file's whole life. **The pill's wave is not this** — an envelope would mean decoding a file to draw an 18px control, so its bars carry the playhead |
| 055 | The sheet keeps both controls; every other way out is a cancel | a sheet whose only button commits leaves the drag gesture carrying a decision; the sheet function ends the take, so a dismissal nobody wired up cannot leave a microphone running |
| 056 | A refused microphone names the OS | the line sits under the action row, which does not move when a word is typed, and the phone's settings are the only way back |
| 057 | The recording controller is the one screen controller kept alive | auto-disposed, Riverpod collected it mid-`start` and the microphone opened with no sheet. **The test that should have caught it added a listener for symmetry** |
| 058 | Transcription is removed; a chit's words are always typed | the whole feature, not a flag: it recognised nothing on the first handset, and a transcript usually absent and occasionally wrong is a worse record than an honest recording |
| 059 | ~~No migrations while there is nothing to migrate~~ | **REVERSED by 099**, which is the trigger it named: v1 goes to phones whose chits somebody would miss. `onUpgrade` threw and the harness was deleted, on the argument that a database the app cannot trust should fail at `open`; that argument survives as the guard on the ladder that replaced it |
| 060 | The open chit's Discard goes; a recording is dropped from its pill | Discard's last unique job was the take, and the take is on the pill. The stamp does not move |
| 061 | A chit in the thread is opened by holding it | one widget, so both screens gain it together, and the row *is* the target. *A tap until 067*: a glancing touch away from firing on every scroll. No swipe-to-delete. Cost: a hold is less discoverable |
| 062 | The editor is a route above the tab shell | pushed, so the back gesture and the back arrow are one exit. A **one-shot read, not a stream**: a row re-emitting under a caret is a screen fighting its own user |
| 063 | An edit is one write; a recording can be removed, replaced or deleted | reverses 014's second half: a Save that changes the words and drops the take must not be two transactions with a window where the row is legal by accident |
| 064 | The prompt is a slip-style sheet; three acts, three words; no undo | over `AlertDialog`, another framework's shape in an app that spent five milestones not looking like one. **The quiet weight always lets go and the bright one always keeps** |
| 065 | A take has one owner, chosen at the tap | `start` takes a sink and holds it for the take's life, over a second controller for the editor or a return value that leaves refused-and-started with nowhere to go |
| 066 | The owner's first look at M6 | **the pin is gone**, a mark that can never be absent saying nothing; **the tick at now is re-read on every save**, the one exception to the one-clock-read rule; **Cancel leaves at once**; **the editor's slip fills the screen** |
| 067 | The owner's third look at M6 | **the pill sits between the stamp and the words**; **a chit is held, not tapped** (061, changed in place); and **`just_audio` carries `playing` across a source change**, so the adapter stops before it loads, held by a fake platform under the real plugin |
| 068 | The caret blinks under reduced motion, and that is a stated limit | the only caret is Flutter's, there is no public way to steady it that does not hide it, and a stock keyboard blinks its own regardless |
| 069 | ~~Press feedback is one widget; the depress is a token~~ | **REVERSED by 070.** What survives is the tab bar off `InkWell`, whose ripple is a second design language |
| 070 | No press feedback; a row's box is always there; the strip arrives by scrolling | the owner called the colour artificial and the depress a sink. **A wrapper that comes and goes is a rebuild** — a `DecoratedBox` swapped in on press disposed the pill's recogniser under the finger |
| 071 | Nothing answers a press; the strip jumps; a thread outlives its empty day | what says a hold landed is the phone's tick, and a page of writing does not light up. **The strip jumps**, reversing 024's second half, travel having drawn the eye to the movement instead of the mark |
| 072 | Three bugs from the fourth look | a pill coming back inherited the last one's playhead; the strip is not drawn until it has rested; and **a list whose children come and go is matched by key or it is not matched at all** |
| 073 | v1 is done, and what building it taught | signed off on a handset, 18 Sep 2026. A feature can be built correctly and still be the wrong feature (058); a fake can be more honest than the thing it stands in for (067). Cost: no migrations, no export, no settings screen, and motion thresholds nobody has walked |
| 074 | The app is **Chitta** wherever the phone says it and **चित्त** wherever it says itself; an entry stays a **chit**; the package is `chitta` | three jobs, no synonyms. The Drift file and the `Chit` classes stay `chit`, so reversing the applicationId still finds what somebody wrote. **Cost: a new `applicationId` is a new app**, installed beside the old one and opening empty. *It also gave first run three tips, deleted with the screen by 094* |
| 075 | The launcher icon is the quote glyph in `--ink` on `--paper`, generated by `flutter_launcher_icons` from two exports | one source of truth for eleven Android sizes, sixteen iOS ones and the web set, over placing thirty files by eye. **Two exports, because a launcher icon is two compositions**: the square, and the glyph alone on transparency for the adaptive foreground, whose outer third Android crops. The glyph sits above centre, as drawn |
| 076 | A screen's heading is one `minTouchTarget` row; the seed carries three months | a chevron's 44px target inflated the row it shares with the words, so switching tab moved the heading; `HeadingRow` holds both still. **Sixty chits over eighty-nine days**, twenty over six weeks having exercised neither the chevrons nor the week 048 leaves out |
| 077 | The archive builds on demand; a pill listens only for itself; one composite index | measured on a handset with 2,000 chits: **a build p50 of 2.6ms rising to 8.8ms with 33–55ms spikes went flat at 0.5ms**. The old screen laid out every page ever loaded on every frame. `(localDay, createdAt)` is the order the archive reads in, so it walks an index. Cost: a schema change, and 059's reinstall |
| 078 | Motion is a word; a speed with no error beside it is believed; the sky is read off quantities | three owner reports. An icon beside a word is two languages on one 11.5px line, reversing 039's icon half. **A train read as `stationary`** because Android sends `0.0` for an accuracy it does not have. Rain is `precipitation >= 0.1mm`, overcast `cloud_cover >= 60%`. **Cost: Open-Meteo's `current` is a grid cell, not a street** |
| 079 | The archive is the visible month, and paging goes with the endless scroll | the grid names a month and the list under it holds that month, so a chevron moves both and the tab is one screen rather than two. Cost: **no continuous scroll back through everything** — reading last March means three taps |
| 080 | The open chit carries no time and says `writing`; a saved chit says `edited`; `updatedAt` is the stamp's own instant at insert | the preview clock was the stalest thing on the screen, two numbers for one chit drifting apart all day. **Removing it answers the question instead of refreshing it.** The insert had read the clock twice, so every chit ever saved would have drawn `edited`. Cost: an edit is legible but not datable |
| 081 | The composer listens for the ambient reading; it never watches it | a `watch` rebuilt the controller when the launch capture landed, throwing away a half-written sentence and orphaning its take. **A controller holding user input may not `watch` anything that arrives on its own** |
| 082 | Tags are parsed out of the words and drawn: a person italic without its `@`, a topic `--ink-faint` with its `#` | italic is a second difference a name can carry alone, where a topic in faint ink alone would differ by colour and nothing else, which §6.4 forbids. `\p{M}` is in the class because a Devanagari matra is a mark, not a letter, and `\p{L}\p{N}` cuts `#चित्त` to `#च`. Cost: the stored text keeps its sigils, so a search parses at read time |
| 083 | A third tab, **find**, and the day group shared under it | 079 made the archive a month, so a chit you could not date had nowhere to be found. **Every chit is read into Dart and its words parsed for tags** — the tags live in the body text and there is no index to ask. *It shipped once as a faceted panel, replaced by 084 before anybody saw it* |
| 084 | find is a **three-screen drill-down, flush right**, one value at a time, over a book of house lines | a filter with four multi-select rows is a query builder, where **find is a way *to* a chit**. Each screen is a route under the tab's branch, go_router already owning what back means. **Bottom while it fits, top once it does not**, measured against the handset rather than guessed at a count |
| 085 | Loading is **null**, not empty; find offers only the axes that go somewhere | `{}` is also the honest answer for *nothing has been written with any of this on it*, and **a screen that cannot tell those apart draws the wrong one first every time**. Reading the values at the root leaves them warm, so the screen below opens with its answer in hand |
| 086 | A tag in a chit is **tappable**, and it **unwinds and re-enters**; find's line carries hints as well as quotes | **`go`, not `push`**: tapping a tag rebuilds find's stack as root → axis → value, so back walks the real path and tag after tag never piles one. `ChitBody` owns and disposes one recognizer per tag, one built in `build` leaking one a frame. The hints share the quote's slot, a caption explaining that content rotates being chrome |
| 087 | The masthead gap closes to `s3` | 36px of air between the wordmark and the heading read as a gap rather than as a margin, and all three tabs change at once because §6.3's *a tab switch does not move the heading* only holds while they agree. *Its other half set first run's three lines, deleted with the screen by 094* |
| 088 | A slug is not a word; the chevrons stay and dim; `--ink-disabled` | the heading printed the route key, so the one axis whose word differs from its name showed the name. The chevrons are pulled out by `(minTouchTarget - glyphSize) / 2` so the *glyph* lands on the gutter. **`--ink-disabled` is 2.4:1, deliberately under §6.4's 3:1 floor** — a disabled control meeting a live one's floor would claim it works |
| 089 | find gets a **faint map** behind its words: the city the newest pinned chit was written in filled, its region in outline, the fix the one bright mark | **Natural Earth, bundled, not tiles fetched** — offline is the premise (009), and a tile request is the location leaving the device on every pan. Filling the host city is what makes it read as somewhere. *On the first screen alone until the owner asked for it one step in*, which is still words to choose between where the screen below is writing. Cost: **1.1 MB**, and it is a region and never a street |
| 090 | The Android 12 splash is handed **the icon as a vector**, and the launch ground stops being white | API 31+ draws the launcher icon at 288dp, so the phone was upscaling the 432px adaptive bitmap; **a larger export cannot fix it**, the generator resampling to the dp spec. The vector carries the same 16% inset, so the splash and the launcher stay one composition. Cost: it is hand-written, so a redrawn glyph is three files |
| 091 | The second tab is **past**, not *calendar* | the word on the tab is the word in the route, the folder and the docs — §4.1 leaves no room for a synonym, and *calendar* named the grid rather than what the tab is for. `MonthGrid` and `MonthBar` keep their names, being components and not the screen |
| 092 | A tag is drawn folded to lower case, and folded at **the parse** | one spelling reaches the chit, the find row and the route, so they cannot drift apart; folding at each draw site instead is a display rule enforced in three places. **The chit keeps what was typed** and the editor shows it. `TagSpan.slug` is gone, the label having become it |
| 093 | find's line turns on **arriving at the tab**, not on the day | a line that changes once a day is read on the first visit and ignored for the rest of it. A drill-down is not an arrival, so it does not move while it is being read; the day seeds the count, so a cold launch is not a rerun of the last one. The hint still comes every fourth one (086) |
| 094 | First run is deleted; the place is asked for at a **save**, and **nothing of ours is drawn about it** | a dialog after a chit is saved is the ask in the context that explains it, where a welcome screen is one every install dismisses. **The OS owns how many times.** **A grant is carried back to the save that won it**, patching the chit just written and the open one — *it was left to the next capture until the owner saw an empty stamp survive a restart*. Reverses 041. Cost: the hold and the tag syntax are taught only by find's hints |
| 095 | **No comments under `lib/` or `test/`** | the code says what it does and the documents say why; a comment is a third home for the reason, outside every §0 rule that keeps the other two true, and the first of the three to go stale. 553 were deleted to write this down. The generated files are exempt, not being written here. Cost: the *why* of a line is now found through the record that names it |
| 096 | Haptics are a **three-step vocabulary**, called through `ChitHaptics` | one tick meant three things by accident. **`selected`** for something now chosen, **`committed`** for something that now exists, **`destroyed`** for something now gone — named rather than called raw, so the mapping lives in one file the way a colour does. **Nothing fires for what the app did itself** (034), nor on a tab switch or a dead chevron |
| 097 | **The tab bar is not drawn until a chit has been written** | on a fresh install *past* is an empty grid and *find* has nothing to look through, so three tabs where two go nowhere promise rooms that are not furnished. One watched `SELECT id … LIMIT 1`, not `watchEvery`, which would keep every chit in memory to answer a boolean. **It does not animate in** (071), and **it goes again if the last chit is deleted**. Cost: it arrives a frame or two after launch, with the thread rather than before it |
| 098 | Release signing reads `android/key.properties`, and **says so out loud when it is missing** | the keystore and its passwords are the owner's and are never committed, so the build has to work without them — but a silent fallback to the debug key ships an APK that installs once and can **never be updated**, the signature not matching any later build. It falls back, and prints that it did, on every release build. Verified end to end with a throwaway key, then the key deleted |
| 099 | **Migrations come back**, and `onUpgrade` throws when no step covers the version asked for | 059's stated trigger, fired: v1 is the first build that reaches a phone whose chits somebody would miss. A schema change is now three things in one commit — the bumped version, a `SchemaStep`, a fresh snapshot — and the guard is what makes a forgotten step fail at `open` rather than as a column quietly missing later. The ladder ships **empty**, so the first change is an addition rather than an archaeology |
| 100 | **`allowBackup="false"`**, and the same for device transfer | Android's default is *true*, so every chit was being copied to Google's servers by a journal whose README says nothing leaves the phone — 004's stated "cost: no backup" was not even true. Cost: **a lost phone is lost chits**, which is 004's cost arriving for real, and what an export format (backlog) would answer |
| 101 | **Extending ambient capture and the stitch are dropped**, not deferred | coarse place cannot name anything offline without a settings screen or a bundled gazetteer, and now-playing needs a notification-listener grant on Android and is unavailable on iOS; the stitch's only form dense enough to hold a year on a phone is the contribution graph the app has refused five times. Cost: §9 loses the item that made it distinctive |
| 102 | **The permission ask stops being gated on the switch, and the OS is let offer the switch itself** | `requestPermission` returned `serviceDisabled` before it ever called `Geolocator.requestPermission`, so **an install with location switched off was never asked for permission at all** — the two are independent on Android, and this shipped in v1. The switch is then offered by letting `getCurrentPosition` reach Play Services' own resolution sheet, **once a run** and never again after a no. Cost: the offer takes a fix, which 094 said asking never would, and **iOS has no such sheet** |
| 103 | **The playhead measures against the length the player decoded, and a finished take holds at its end** | the row's duration is wall-clock across the take and counted the encoder opening as audio, so the bars divided by a length the audio never reached and **one or two never lit** — worse the shorter the take. Reading the length off `just_audio` fixes **takes already saved**, no migration; the recorder now starts its clock after `start()` returns, which only helps new ones. Completion used to go silent, which reset the pill a frame before it was full; it now rests lit and seeks on the next tap |
