# Architecture decisions

What was decided, and the reason that mattered. A supersession edits its record in place (CLAUDE.md
§0.2). **018, 026 and 030 are retired**, not reused — 018 moved to PACKAGES.md, 026 was absorbed by
040, 030 by 031. **021** is superseded and kept, a reversal being legible only beside what it
reversed. Everything else is accepted.

| | Decision | Why, and what it costs |
|---|---|---|
| 001 | Riverpod, with code generation | the screens are four readings of one table that must never disagree; Riverpod's graph gives that free |
| 002 | Three layers, and `features` never imports `data` | the seam is what lets a test refuse a microphone and a sync layer arrive later |
| 003 | Drift over a document store | nearly every screen is an aggregate query, which SQL answers in the database rather than in Dart |
| 004 | Local-only for v1, with the seams for sync | obliges a client-generated UUID per row — retrofitting stable ids onto a synced table is the expensive version. Cost: no backup |
| 005 | ~~Speech-to-text runs on the device~~ | **REMOVED by 058.** Over cloud STT, which means every recorded thought leaving a private journal. Kept, 013 and 014 citing it |
| 006 | A denormalised local day on every chit | a chit written at 00:20 belongs to that morning forever, and deriving the day at read time changes the answer across a timezone move |
| 007 | Ambient capture is best-effort and never blocks | a signal that does not arrive is null and is not drawn; capture may never delay the composer or fail a save |
| 008 | Audio on the filesystem, path in the row | stored **relative**, an absolute iOS container path being dead after the next update |
| 009 | Fonts bundled, not fetched | offline is a requirement and a fallback serif is a visibly different app. Cost: ~1.8 MB |
| 010 | Design tokens as a `ThemeExtension` | the accent's two weights and motion's per-kind reduced-motion behaviour are rules, enforceable only if one place knows them |
| 011 | `go_router` with a persistent tab shell | returning to a tab costs a fade, not a rebuild; the recording sheet stays a sheet, dismissing it not being a back navigation |
| 012 | An injected clock | three specified behaviours are functions of the current time; a fake clock makes the midnight rollover tested rather than discovered |
| 013 | A chit is text, audio, or both | independently nullable with at least one present. Its provenance half went with 058 |
| 014 | Saved chits are editable, and an edit never moves the moment | **audio half reversed by 063.** `createdAt`, `localDay` and the ambient fields are not parameters of any edit |
| 015 | Variable fonts, and weight through `fontVariations` | **a variable font renders at 400 whatever `fontWeight` says** — a silent failure, so every style sets both |
| 016 | Precise location first, coarse as the fallback | a neighbourhood fix cannot separate the coarse place labels the backlog wants. The row is precise enough to reconstruct an address, which is why 004 is load-bearing |
| 017 | The chit editor is a screen, and leaving it asks | a second editable field among the thread's rows makes it ambiguous which one a tap targets |
| 019 | Android and iOS only; `web/` stays | responsive web is planned, and regenerating it would be the only gain from deleting it |
| 020 | Reducing motion never makes a fade slower | press is the only acknowledgement a phone gives a finger. Found by a property test that failed on first run |
| 021 | ~~A chit is stamped when it is opened~~ | **SUPERSEDED by 040** — it filed a chit opened at 23:58 and saved at 00:05 on the previous day |
| 022 | The seal means now; a record is ink | over giving the accent to anything that mattered, which on a working screen is everything. Cost: density reads quieter |
| 023 | The field is live, but it does not take focus | a keyboard on every launch covers the thread and the strip, and reading back is as common a reason to open a journal as writing |
| 024 | The day arc becomes the timeline | three days, midnight to midnight, each mark at its actual time — the old window clamped 00:20 onto the same pixel as 5:00. *Resting at now was a scroll until 071 made it a jump* |
| 025 | The weather service takes no position | taking one would make weather wait on the slow precise fix and couple the two failures. Cost: the condition can be for where you were |
| 027 | An ambient loop is not a pace | the period belongs to the component that loops; one table holding both invites comparing quantities that are not comparable |
| 028 | The caret is the platform's, and chit draws none | an app that is animating when you open it is asking for something |
| 029 | The prompt reads the stamp | a generic prompt in front of a line reading `3:42 pm raining` ignores it. Every prompt stays a question — tested, since copy fails quietly |
| 031 | No widget tests | screen tests asserted tree structure rather than the visual claim and could not complete real I/O. Cost: 251 tests became 171, and the field-focus and stamp-timing rules have only a handset pass |
| 032 | One day is one screen, and now rests in the middle | the unlabelled boundaries arrive where a reader expects them; resting at the end would pin 00:20 to the left edge |
| 033 | Today re-reads the clock at midnight | worse than a stale date, the first chit of the new day would save outside the drawn window and get no mark. Cost: it fires on the wall clock |
| 034 | A day passing is a haptic | the boundaries are deliberately hard to read, leaving nothing else to say you have scrolled into yesterday. Silent when the strip moves itself |
| 035 | Days with nothing in them are not drawn | narrows 024: a bare unlabelled line cannot be told from broken. A quiet day *between* two written ones still draws |
| 036 | Now is a tick, not a dot | over two built alternatives — a chit saved now sat *inside* the ring, and the disc that replaced it became the loudest thing on the screen |
| 037 | Motion is read off the position fix | speed is already on the fix, so a third signal costs no package or permission; an accelerometer cannot measure speed and the activity APIs need a second dialog. An uncertain reading degrades to `stationary`, so noise can slow a chit down and never put a plane on one. No `running` or `cycling` |
| 038 | The stamp carries one ambient fact, ranked | three items at 11.5px is a ceiling, not a preference, and the two facts are usually alternatives anyway |
| 039 | Motion is drawn in the thread, not only on the open chit | the pin's reasoning reverses: almost no chit has a motion, so a word on two rows out of twelve carries real information. *It was an icon rather than a word until 078*, on the argument that an English phrase for motion reads like a fitness tracker |
| 040 | A chit is stamped when it is saved | reverses 021, absorbs 026: it removes the wrong-day class rather than patching its paths. Cost: the preview can disagree, and does not tick |
| 041 | Permission is asked once, behind a screen of our own | a system prompt cannot say what it buys, and asking in context puts a dialog on the one path that must cost nothing. Cost: a refusal is a dead end |
| 042 | Ambience is captured at launch and at save, never between | over capturing on every chit open, which made four taps cost four fixes. The row is written first and patched after, and **the patch moves neither `createdAt` nor `updatedAt`** |
| 043 | The weather mapping | `windy` at 7.0 m/s, lower firing on most Mumbai afternoons; `wind_speed_unit=ms` pinned at the request, 8 km/h and 8 m/s being opposite verdicts; a clear sky with no `is_day` says nothing; snow maps to `overcast`. **Rain and cloud moved off the summary code onto the measured quantities in 078** |
| 044 | Twelve seconds, and a stale place beats no place | the fallback to a last known fix **drops its kinematics**, a stale speed otherwise claiming `traveling` about a desk |
| 045 | A reading stays good for one minute, **and said five until the owner walked it back** | five chits over ten minutes bought five identical fixes, so the window exists; five minutes was the wrong size for it. Set by the **place**, the shortest-lived signal — and a place is what moves fastest, so the window has to be shorter than a walk to the next room. Cost: a burst of chits now buys a fix a minute rather than one for the sitting, which is a battery cost nobody has measured against the honesty it buys. A chit on a train can still say `stationary`, for a minute rather than five |
| 046 | Today's ring sits on paper, not on the tile | `--seal` on a density fill failed the 3:1 floor from three chits on, and a lighter ring breaks the one-accent rule |
| 047 | The calendar draws only where something was written | weeks and months that never will be written in read as days with nothing written in them. No chevron where there is nowhere to go |
| 048 | Every quiet week collapses, wherever it falls | narrows 047: the objection does not survive once day numbers are on the tiles. Cost: a month is no longer a calendar shape |
| 049 | The calendar holds its last answer while the next is in flight | 007 read to its end — an empty state drawn while the real answer is in flight is a wrong answer, not a slow one |
| 050 | A day boundary is the tick at now, hanging below the line | at 4px a chit written near midnight hid it, so the signal failed exactly when a day was full |
| 051 | A record is short | one table row, not a five-headed essay; *it was a paragraph until this file became a table*, and both passes were applied retroactively. Cost: *how* a decision was reached now lives only in git |
| 052 | The recorder times a take on the clock, and reports a level | reading the duration back opens a decoder on the save path for one integer; the waveform draws a number, and the scale is the data layer's business |
| 053 | ~~The recogniser streams a split transcript~~ | **REMOVED by 058.** Kept, 054 and 055 citing it |
| 054 | A take goes through the repository; the wave is a window of levels | one door owns the temp file's whole life. **The pill's wave is not this** — an envelope would mean decoding a file to draw an 18px control, so its bars carry the playhead |
| 055 | The sheet keeps both controls; every other way out is a cancel | a sheet whose only button commits leaves the drag gesture carrying a decision; the sheet function ends the take, so a dismissal nobody wired up cannot leave a microphone running |
| 056 | A refused microphone names the OS | the line sits under the action row, which does not move when a word is typed, and the phone's settings are the only way back |
| 057 | The recording controller is the one screen controller kept alive | a take begins on the tap and the sheet exists only once `start` returns; auto-disposed, Riverpod collected it mid-`start` and the microphone opened with no sheet. **The test that should have caught it added a listener for symmetry** |
| 058 | Transcription is removed; a chit's words are always typed | the whole feature, not a flag: it recognised nothing on the first handset, and a transcript usually absent and occasionally wrong is a worse record than an honest recording |
| 059 | No migrations while there is nothing to migrate | `onUpgrade` throws, a database the app cannot trust having to fail at `open`. **Cost: the first non-development install cannot receive a schema change without losing everything** — open item 38 |
| 060 | The open chit's Discard goes; a recording is dropped from its pill | Discard's last unique job was the take, and the take is on the pill. The stamp does not move |
| 061 | A chit in the thread is opened by holding it | one widget, so both screens gain it together, and the row *is* the target. *A tap until 067*: a glancing touch away from firing on every scroll. No swipe-to-delete. Cost: a hold is less discoverable |
| 062 | The editor is a route above the tab shell | pushed, so the back gesture and the back arrow are one exit. A **one-shot read, not a stream**: a row re-emitting under a caret is a screen fighting its own user |
| 063 | An edit is one write; a recording can be removed, replaced or deleted | reverses 014's second half. One write, because a Save that changes the words and drops the take must not be two transactions with a window where the row is legal by accident — and the invariant then has one place to be asserted, **before any file moves** |
| 064 | The prompt is a slip-style sheet; three acts, three words; no undo | over `AlertDialog`, another framework's shape in an app that spent five milestones not looking like one. **The quiet weight always lets go and the bright one always keeps** |
| 065 | A take has one owner, chosen at the tap | `start` takes a sink and holds it for the take's life, over a second controller for the editor or a return value that leaves refused-and-started with nowhere to go |
| 066 | The owner's first look at M6 | **the pin is gone**, a mark that can never be absent saying nothing, which narrows 016's display half to nothing; **the tick at now is re-read on every save**, the one exception to the one-clock-read rule, since a chit saved twenty minutes after launch landed *ahead* of now; **Cancel leaves at once** while the back arrow still asks; **the editor's slip fills the screen** |
| 067 | The owner's third look at M6 | **the pill sits between the stamp and the words**, as on the open chit; **a chit is held, not tapped** (061, changed in place); and **a pill tapped while another sounded was heard but never lit** — `just_audio` carries `playing` across a source change, so the adapter now stops before it loads, held by a test standing a fake platform under the real plugin |
| 068 | The caret blinks under reduced motion, and that is a stated limit | the only caret is Flutter's, there is no public way to steady it that does not hide it, and a stock keyboard blinks its own regardless |
| 069 | ~~Press feedback is one widget; the depress is a token~~ | **REVERSED by 070.** What survives is the tab bar off `InkWell`, whose ripple is a second design language |
| 070 | No press feedback; a row's box is always there; the strip arrives by scrolling | the owner called the colour artificial and the depress a sink. **A `DecoratedBox` swapped in on press changed the shape of the tree**, so Flutter rebuilt the subtree and disposed the pill's recogniser on the frame the finger landed — a recording in the thread could not be played at all. **A wrapper that comes and goes is a rebuild**, which is why `Arrival` stays mounted and is told whether to play |
| 071 | Nothing answers a press; the strip jumps; a thread outlives its empty day | what says a hold landed is the phone's tick, and a page of writing does not light up. **The strip jumps**, reversing 024's second half, travel having drawn the eye to the movement instead of the mark. **The thread is mounted on an empty day**, since it tells a new row from an old one by remembering what it drew last time |
| 072 | Three bugs from the fourth look | **a pill coming back inherited the last one's playhead**, the position stream still answering for the file that is leaving; **the strip is not drawn until it has rested**, where it rests being a function of the viewport; and **the thread is keyed** — **a list whose children come and go is matched by key or it is not matched at all**, the same shape as 070's wrapper |
| 073 | v1 is done, and what building it taught | signed off on a handset, 18 Sep 2026. **A feature can be built correctly and still be the wrong feature** (058); **a fake can be more honest than the thing it stands in for** (067); **a wrapper that comes and goes is a rebuild, and a list whose children come and go is matched by key or not at all** (070, 072); **an affordance on a scrolling surface is decided by a thumb, not at a desk** (061). Cost: no migrations, no export, no settings screen, and motion thresholds nobody has walked |
| 074 | The app is **Chitta** wherever the phone says it and **चित्त** wherever it says itself; an entry stays a **chit**; the package is `chitta`; first run opens with three tips | the drawer, the switcher and the two iOS usage strings carry the name a person would say out loud, the wordmark carries the word it is named after, and one entry keeps the short word — three jobs, no synonyms. *The wordmark was briefly Latin, with the चित्त mark taken off it*; it is now the mark itself at **19px**, where the old one beside it was 11.5, Devanagari setting visibly smaller than Latin at a size. The identifiers follow: the Dart package, `applicationId` and the bundle id are all `chitta`. **Two names deliberately do not** — the Drift file and the two preference keys still read `chit`, so that reversing the applicationId still finds the chits somebody wrote. **Cost: a new `applicationId` is a new app**, installed beside the old one and opening empty. **The tips pay 061's stated cost** — a hold is the one gesture a scrolling surface cannot advertise, and first run is the only place left to say so |
| 075 | The launcher icon is the quote glyph on `--paper`, generated by `flutter_launcher_icons` from two exports | one source of truth for eleven Android sizes, sixteen iOS ones and the web set, run by hand and committed, over placing thirty files by eye. **Two exports, because a launcher icon is two compositions**: the square as drawn for iOS and legacy Android, and the glyph alone on transparency for the adaptive foreground, where Android crops the outer third and a dark square inside the system's mask would read as a mistake. The ground is `--paper` so the icon and the first screen it opens are one colour. **The glyph sits above centre, as drawn** — checked in the drawer under a round mask, where it clears the crop |
| 076 | A screen's heading is one `minTouchTarget` row; first run does not scroll; the seed carries three months | the date and the month sat 15px apart — `s4` against `s5`, and a chevron's 44px target inflating the row it shares with the words — so switching tab moved the heading. `HeadingRow` holds both still, and holds them still on a month with no chevron to draw. **First run does not scroll**: a welcome screen that slides under the thumb reads as unfinished, so the copy is cut until it fits. Cost: a ceiling on that copy, open item 44. **Sixty chits over eighty-nine days**, where twenty over six weeks exercised neither the chevrons, nor a month with more in it than one screen, nor the week a past month leaves out (048) |
| 077 | The archive builds on demand; a pill listens only for itself; one composite index | measured on a handset with 2,000 chits, not argued: **scrolling the archive went from a build p50 of 2.6ms rising to 8.8ms as pages accumulated, with 33–55ms spikes, to a flat 0.5ms and nothing over budget**. The old screen put the whole loaded archive in one `SliverToBoxAdapter`, so every page ever loaded was laid out on every frame; `SliverList.builder` builds what is on screen. *A block of groups stayed eager for the entrance until 079 removed both.* `AudioPill` watched the whole `Playback`, so one playhead rebuilt every pill on screen ten times a second; a `select` returning a record makes that its own row's business. `(localDay, createdAt)` is the order the archive reads in, so its `ORDER BY` walks an index instead of sorting the table — **replacing three indexes, one of which served a backlog item and nothing else**. Cost: a schema change, so an install carrying the old shape is reinstalled (059) |
| 078 | Motion is a word; a speed with no error beside it is believed; the sky is read off quantities | three reports from the owner, each wrong in a different way. **Motion reads as a word** — `walking`, `travelling`, `flying` — reversing 039's icon half: an icon beside a word is two languages on one 11.5px line, and the fitness-tracker worry was about phrases, not about the plain gerund the weather already speaks in. `MotionIcon` is deleted. **A train read as `stationary`** because Android sends `0.0` for a speed accuracy it does not have and the gate read that as noise — open item 18, which predicted exactly this; the gate now refuses only a reading noisier than the speed it carries, and `Position.hasSpeed`/`hasSpeedAccuracy` separate *not reported* from *reported zero*. **Rain is `precipitation >= 0.1mm` and overcast is `cloud_cover >= 60%`**, so a drizzle code with nothing under it no longer says `raining` and item 28's partly-cloudy question answers itself; the codes stay as the fallback when a quantity is missing, and fog and snow still close the sky whatever the cloud says. **Cost: Open-Meteo's `current` is model output on a grid, not an observation of a street** — no threshold fixes a cell that is raining when you are not |
| 079 | The archive is the visible month, and paging goes with the endless scroll | the owner's call, and it makes the tab one screen instead of two: the grid names a month and the list under it holds that month, so a chevron moves both. **`ArchivePages`, `archiveLimit` and the scroll listener that widened the query are deleted** — a month is the page, and there is nothing left to page. `watchArchive` takes a day range rather than a limit, which the `(localDay, createdAt)` index of 077 answers by walking. **The archive's staggered entrance goes too**: a month swap that replays a stagger on every chevron reads as a page rebuilding, and the list is now short enough that nothing needed the eager block the entrance forced. Cost: **no continuous scroll back through everything** — reading last March means three taps, and a chit you cannot date is harder to find than it was |
| 080 | The open chit carries no time and says `writing`; a saved chit says `edited`; `updatedAt` is the stamp's own instant at insert | the preview clock was the stalest thing on the screen — open item 24, where the slip said when it was opened and the row said when it was saved, two numbers for one chit that drifted apart all day. **Removing it answers the question instead of refreshing it**: nothing on the open chit claims a time, so nothing can be wrong about one, and 042's five-minute staleness is left owning only the weather. The slot is not left empty — an empty line would move the field under the thumb the moment a signal landed, so it reads `writing` until a fact displaces it, which on a phone that refused location is forever. **`edited` is the column `updatedAt` finally spending itself**: written since 014 and drawn nowhere, so a thread could not say which chits had been gone back to. It is the word and not the hour, three items at 11.5px being 038's ceiling. **The insert now writes `capturedAt` into `updatedAt` rather than reading the clock a second time** — the two reads were milliseconds and an audio file-move apart, so every chit ever saved would have drawn `edited`; the fake clock hid it, DATA-MODEL.md §1 had claimed the equality since it was written, and the code had never honoured it. Cost: an edit is legible but not datable, and `wasEdited` is an ordering comparison rather than an invariant — a `const` freezed assert cannot call `isBefore`, so the repository holds it alone rather than buying a `CHECK` and 059's reinstall |
| 081 | The composer listens for the ambient reading; it never watches it | **a bug the owner hit on the first real use**: `build()` called `ref.watch(ambientSignalsProvider)`, so the launch capture landing — seconds after the app opens, which is exactly when somebody is writing their first sentence — rebuilt the controller and returned a blank `ComposerState`. The words went, and a kept take went with them, leaving its temp file with no owner. **`ref.listen` patches the stamp instead of rebuilding the state**, and the patch keeps `capturedAt` so the hour still picks the prompt (029). The general form: **a controller holding user input may not `watch` anything that arrives on its own** — watching is for state that may be recomputed, and half a sentence may not be. Nothing caught it because the composer's tests primed the signals before opening the chit, never during; the two that now guard it fail against the old line |
| 082 | Tags are parsed out of the words and drawn: a person italic without its `@`, a topic `--ink-faint` with its `#` | the rendering half of backlog item 8, the owner's call, and the asymmetry is 064's floor doing the work — **italic is a second difference a name can carry on its own**, so `@` has no job left once the slope says *person*; a topic set only in faint ink would differ from body text by colour and nothing else, which **§6.4 forbids outright**, so its sigil stays and is the difference colour is not allowed to be. **An underscore inside a tag draws as a space** — a tag has to be one word to type and two to read — and a run of them is one space, not a gap nobody can see. **The grammar is a lookbehind and a mark class**: a sigil only counts at a word start, so `work@example.com` is an address; a label ends on a letter, a digit or a mark, so a trailing underscore falls outside; and `\p{M}` is in the class because **a Devanagari matra is a combining mark, not a letter, and `\p{L}\p{N}` alone cuts `#चित्त` down to `#च`** — found by the test that was written for it. **Nothing is tappable**: a `TapGestureRecognizer` would win the gesture arena against the row's hold, which is the trap M6 left the note about, so this is a `TextSpan` tree and the row stays the target. The screen reader is given the drawn form and not the row, `ChitTags.spoken` being the same walk. Cost: the stored text keeps its sigils and underscores, so a search will parse at read time until an index earns its place, and **the editor shows what was typed** rather than what was drawn |
| 083 | A third tab, **find**, and the day group shared under it | the owner's call, and it is **item 47's answer and backlog 2's** in one screen — 079 made the archive a month, so a chit you could not date had nowhere to be found. **It shipped once as a faceted panel** — four rows of words, multi-select, any-within-a-row and all-across-them — and **084 replaced that whole design before anybody saw it on a handset**; what survives here is the tab, the four axes, and the moves that outlast a layout. **Every chit is read into Dart and its words parsed for tags**: the tags live in the body text and there is no index to ask, so find scans. 077 deleted the `weather` index *because it served this and nothing else*; it is not back, and bringing it back is a schema change and 059's reinstall. `ArchiveDay` and `groupByDay` moved to `shared/` as `DayGroup`, the heading became `DayGroupView`, and the ambient words moved to `domain/ambient/ambient_words.dart` — all knowledge two screens now hold, and a second copy of the word `travelling` is how §3.6's *the same words wherever they appear* stops being true |
| 084 | find is a **three-screen drill-down, flush right**, one value at a time, over a book of house lines | the owner rejected 083's panel on sight of the description: a filter with four multi-select rows is a query builder, and **find is a way *to* a chit**. Three screens — the four axes, one axis' values, that value's chits — and **each is a route under the tab's branch**, because the drill-down has a back and go_router already owns what back means; state plus a `PopScope` would be hand-rolling next to the package that has the seam (CLAUDE.md §4.2). **The column is flush right, the one surface in the app that is not left-aligned** — the owner's reachability argument, and it holds because this column is *targets* and not prose; the two readings of their own instruction contradicted each other and were asked about rather than guessed. **Bottom while it fits, top once it does not**, measured against the handset by `sitsAtBottom` rather than guessed at a count: five weathers fit anywhere, a year of tags fits nowhere, and an overflowed list anchored at the bottom would open on its *least* written row. The fitting case is a `Column` and the overflowing case a `ListView.builder`, so the unbounded one stays lazy (ARCHITECTURE §1). **Alphabetical for weather and motion, most-written-first for people and topics** — a short list a reader knows the whole of is *found* alphabetically, a list that grows without limit needs its useful rows to rise; ties break alphabetically or two tags written once each swap on every save. **The lines are unattributed house lines** (`quotes.dart`, forty-five of them, indexed by the local day): a misattributed quotation is a defect that ships and cannot be checked from inside the app, and a line that changed on every glance would be 027's ambient loop. Cost: **two values at once is gone**, and the label drawn for a tag is the *latest* spelling written, the rows arriving newest first |
| 085 | Loading is **null**, not empty; find offers only the axes that go somewhere | **a glitch the owner saw on a handset**: tapping a word opened a screen that drew its empty state for one frame and then replaced it, so the content appeared at the bottom of the screen and jumped to the top. `AxisValues` returned `{}` while the stream was still loading, and `{}` is also the honest answer for *nothing has been written with any of this on it* — **a screen that cannot tell those apart draws the wrong one first every time**. Both now return `null` until the rows arrive, which is 049's pattern already used by the archive. The jump was the second half: an empty column fits, so 084's `sitsAtBottom` put it at the bottom, and the real list did not fit and went to the top. **The root screen draws only axes with something on them** — the owner's call, and the same argument §4.1 uses against a control that does nothing; it also *fixes the glitch properly*, because reading the values at the root is what leaves them warm, so the screen below opens with its answer already in hand rather than loading. Cost: the first open of the find tab shows the line alone for a beat, which is the one place the load is still visible — and an axis appears in the column the moment its first chit is written, which is a list that changes under a reader who is not looking at it |
| 086 | A tag in a chit is **tappable**, and it **unwinds and re-enters**; find's line carries hints as well as quotes | backlog item 8's other half, and the way in that 084 left find without. **`go`, not `push`**: tapping `@anant` from inside `#rent` rebuilds find's stack as root → people → anant, so back always walks the real path up and tapping tag after tag never piles one — the owner's call, and it is also the only option where the axis screen underneath matches the value on top.
